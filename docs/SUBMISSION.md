# Hackathon Submission Checklist

## Boundary gate
- [ ] Original agent on Amazon Bedrock Managed Agents or eligible Bedrock AgentCore managed harness.
- [ ] One defined job.
- [ ] Written rule set: allowed access, refusals and edge cases.
- [ ] Architecture description/diagram.
- [ ] Explain how each rule is enforced.
- [ ] At least 5 adversarial prompts.
- [ ] At least 1 prompt injection.
- [ ] Document attack intent and actual response.
- [ ] Working demo.
- [ ] At least one screenshot of the agent running.
- [ ] Public code repository or publicly visible demo.
- [ ] Public repo uses an approved OSI open-source license.
- [ ] Project published on AWS Builder Center.
- [ ] Build process and rule failures/fixes documented.
- [ ] Verify eligibility and country restrictions in the official rules.

## Judging story
- [ ] Technical innovation and originality.
- [ ] Craft and execution.
- [ ] Usefulness and impact.
- [ ] Creativity and storytelling.

## Final verification
- [ ] All links work.
- [ ] README is clear.
- [ ] No credentials, personal data or sensitive logs in repo.
- [ ] Tests accurately report actual results.
- [ ] Screenshots reflect real running software.
- [ ] Submission completed before deadline.
